# Работа с qwen3-coder:30b в Tbot через VS Code

Этот проект подготовлен для локального AI-агента на модели
`qwen3-coder:30b`. Главная роль агента: объяснять существующий код и делать
небольшие точечные правки без крупных архитектурных изменений.

## Что добавлено в проект

- `AGENTS.md` - короткие постоянные правила для AI-агентов в корне проекта.
- `.ai/qwen3-coder-agent.md` - готовый prompt/custom instructions для
  `qwen3-coder:30b`.
- `docs/qwen3_coder_vscode.md` - эта инструкция по работе из VS Code.

## Как подключить модель

1. Установи и запусти Ollama.
2. Скачай модель:

```powershell
ollama pull qwen3-coder:30b
```

3. Проверь, что модель отвечает:

```powershell
ollama run qwen3-coder:30b "Скажи коротко, что ты готов работать с Python-проектом."
```

4. В VS Code установи агентное расширение, которое умеет работать с Ollama или
   OpenAI-compatible local endpoint. Подходящие варианты:

- Continue;
- Roo Code;
- Cline;
- другое расширение с поддержкой Ollama.

5. В настройках расширения укажи:

```text
Provider: Ollama
Model: qwen3-coder:30b
Base URL: http://localhost:11434
```

Если расширение просит OpenAI-compatible endpoint, обычно используется:

```text
Base URL: http://localhost:11434/v1
Model: qwen3-coder:30b
API key: любое непустое значение, например ollama
```

6. В custom instructions / system prompt вставь содержимое:

```text
.ai/qwen3-coder-agent.md
```

Если расширение автоматически читает `AGENTS.md`, всё равно полезно добавить
`.ai/qwen3-coder-agent.md` как основной prompt: он точнее описывает роль
локального агента.

## Как открыть проект

В VS Code открывай именно папку проекта:

```powershell
code C:\Users\vladimir\Desktop\Investment\Tbot
```

Перед задачами на изменение кода желательно, чтобы агент видел эти файлы:

- `AGENTS.md`
- `PROJECT_INSTRUCTIONS.md`
- `AGENT_BEHAVIOR.md`
- нужный файл из `app/...`
- ближайший тест из `tests/...`

## Как с ним работать

Для объяснений проси явно не редактировать код:

```text
Объясни, как работает app/services/orders.py. Код не меняй.
```

```text
Найди поток подтверждения заявки от Telegram-команды до T-Invest. Объясни по файлам.
```

Для правок задавай узкий scope:

```text
Исправь только обработку ошибки в app/services/price_conditions.py.
Архитектуру не меняй. После правки запусти ближайшие тесты.
```

```text
Добавь проверку в существующий сервис, не создавай новый слой.
Перед изменениями скажи, какие файлы будешь трогать.
```

Для ревью:

```text
Посмотри изменения в git diff и найди риски: безопасность торговли, тесты,
CSRF/auth, сохранение текущего поведения. Код не меняй.
```

## Что агенту запрещено

Не разрешай агенту делать такие задачи без отдельного плана:

- "добавь автоторговлю";
- "пусть ИИ сам покупает/продает";
- "добавь торговые сигналы в runtime";
- "перепиши архитектуру";
- "почисти весь проект";
- "удали legacy-модули";
- "измени `.env`, `users.json`, базу данных или токены".

Для Tbot безопасный формат такой: агент объясняет, ищет место изменения,
делает маленькую правку, запускает релевантные тесты, показывает итог.

## Проверка после правок

Основная команда проверки:

```powershell
.\venv312\Scripts\python.exe -m unittest discover -q
```

Для небольших задач сначала запускай один-два ближайших теста, например:

```powershell
.\venv312\Scripts\python.exe -m unittest tests.test_web_routes -q
.\venv312\Scripts\python.exe -m unittest tests.test_plan_runner -q
```

Если правка затрагивает заявки, production/sandbox режим, планы, anti-greedy,
auth или CSRF, проси агента запускать соответствующие тесты и объяснять, какой
риск они закрывают.

## Практический рабочий процесс

1. Открой задачу в VS Code.
2. Попроси агента сначала объяснить нужный участок.
3. Попроси назвать файлы, которые он собирается менять.
4. Разреши маленькую правку.
5. Проверь diff.
6. Запусти тесты.
7. Если результат нормальный, только потом переходи к следующей маленькой
   задаче.

Такой режим подходит для `qwen3-coder:30b`: модель будет полезна как локальный
помощник по чтению и точечному дописыванию кода, но не будет вести проект к
случайной перестройке архитектуры.
