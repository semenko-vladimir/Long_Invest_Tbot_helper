# Бенчмарк экономического анализа новостей

`scripts/economic_news_benchmark.py` — отдельный инструмент проекта Tbot для
сравнения локальных моделей. Он не запускается Telegram-ботом, не читает
брокерские токены и не создаёт торговых поручений. В тесте используются шесть
вымышленных экономических новостей из `scripts/economic_news_cases.json`.

Для запуска нужны Python 3.10+ и Ollama либо локальные GGUF-модели LM Studio.
Дополнительных Python-пакетов бенчмарку не требуется. Файлы
`scripts/agent_benchmark.py` и `scripts/inspect_agent_models.py` содержат общие
функции обнаружения моделей и управления запуском. Все четыре файла должны
оставаться в одном каталоге.

## Запуск

На ноутбуке из корня Tbot:

```powershell
.\venv312\Scripts\python.exe -B scripts\economic_news_benchmark.py --serve --host 127.0.0.1 --port 8765
```

На сервере из корня Tbot:

```bash
python3 -B scripts/economic_news_benchmark.py --serve --host 127.0.0.1 --port 8765
```

Откройте `http://127.0.0.1:8765/` на машине запуска. Для просмотра с другой
машины задайте её доступный адрес через `--host`; не публикуйте панель в
интернет без авторизации. Запускайте один прогон за раз, чтобы модели не
мешали друг другу. Текущий серверный прогон по-прежнему использует отдельный
каталог `/home/feelwent/apps/economic-news-benchmark`; копирование кода в Tbot
его не переключает и не прерывает.

По умолчанию программа обнаруживает скачанные модели, даёт каждой попытке
до 600 секунд и максимум пять попыток получить полный ответ. После первой
удачной попытки выполняется до пяти дополнительных попыток для поиска более
быстрых настроек. Между моделями — пауза 600 секунд. Текущие лимиты можно
увидеть через `--help` и в `run.json` каждого прогона.

Для проверки одной модели:

```powershell
.\venv312\Scripts\python.exe -B scripts\economic_news_benchmark.py --model "ИМЯ_МОДЕЛИ" --cooldown-seconds 0
```

Для продолжения прерванного прогона:

```powershell
.\venv312\Scripts\python.exe -B scripts\economic_news_benchmark.py --resume "C:\путь\к\отчёту"
```

Отчёты по умолчанию сохраняются в `~/economic-news-reports`, вне репозитория.
`summary.md` содержит рейтинг, `review.md` — ответы и ошибки для ручной
проверки, `summary.json` — машиночитаемый итог. Папки `models/<модель>`
содержат каждую попытку, её настройки, оценку и журнал решений. Панель
показывает результаты по мере появления файлов.

Оценка за сюжет включает направление эффекта (8 баллов), расчёт (6), выбор
документов (5) и предел допустимого вывода (5). Объяснения сохраняются для
ручной проверки, но автоматический балл за них не начисляется. Рейтинг
относится только к этому фиксированному набору новостей.
